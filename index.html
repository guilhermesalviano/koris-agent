An autonomous AI assistant, running on your own infrastructure

Koris Assistant is a TypeScript framework for building AI assistants with pluggable channels, extensible skills, and memory that persists across sessions — not just within a chat window.

How it works

Five steps between download and a running agent.

01View releases →

Download

# Download the source zip from the latest release

Grab the latest release from GitHub and unzip it.

02

Unzip

unzip koris-<version>.zip
cd koris-<version>

Extract the archive and enter the project folder.

03

Install dependencies

pnpm install

Installs all workspace dependencies (root, web/, landing/).

04

Configure & build

pnpm build && pnpm app

No settings.json yet? You’ll land in a setup wizard automatically — no manual editing.

05

Open the dashboard

open http://localhost:3000

Finish the wizard (AI provider, Telegram/WhatsApp, personal info) and your assistant is live.

What's inside

Everything you need to run your own agent.

Modular plugins & skills

Extend the agent with channel plugins and markdown-defined skills, without touching core code.

Persistent memory

A SQLite-backed memory store keeps summaries, facts, and lessons learned across sessions.

Multi-channel

Talk to your agent over Telegram, WhatsApp, a terminal UI, or the web dashboard.

Pluggable AI providers

Bring your own model — run against Ollama, NVIDIA, or a mock provider for testing.

Tools & heartbeats

Executes shell commands, curl requests, and search, plus scheduled heartbeat agents that run on their own.
