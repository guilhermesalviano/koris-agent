Self-hosted · Open source

An autonomous AI agent, running on your own infrastructure

Koris Assistant is a TypeScript framework for building AI agents with pluggable channels, extensible skills, and memory that persists across sessions — not just within a chat window.

Install

pnpm install

Then cp settings.example.json settings.json and pnpm build.

Run

pnpm app

Starts the agent and web dashboard on localhost:3000.

Modular plugins & skills

Extend the agent with channel plugins and markdown-defined skills, without touching core code.

Persistent memory

A SQLite-backed memory store keeps summaries, facts, and lessons learned across sessions.

Multi-channel

Talk to your agent over Telegram, WhatsApp, a terminal UI, or the web dashboard.

Pluggable AI providers

Bring your own model &mdash; run against Ollama, NVIDIA, or a mock provider for testing.

Tools & heartbeats

Executes shell commands, curl requests, and search, plus scheduled heartbeat agents that run on their own.
